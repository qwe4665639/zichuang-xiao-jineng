# 自创小技能

我自己做的一些「小技能」，用来教会 AI 助手做某件具体的事。

不用懂代码 —— 只要你会复制粘贴、会跟 AI 说一句话，就能用。

---

## 一、先说清楚：「技能」是什么

你大概已经在用 AI 了（DeepSeek、ChatGPT、Claude、Cursor……里面那个能跟你聊天的东西）。

它们很聪明，但有些活它们不知道**你想怎么干** —— 比如让它画张图，它可能甩给你一堆看不懂的文字；让它写周报，它写得像机器人。

**技能，就是一份写好的说明书：你把它交给 AI，它以后遇到这类活，就照着说明书来。**

打个比方：

- AI 像一个新来的同事 —— 什么都懂一点，但不知道你们这儿的习惯；
- 技能就是一份《我们这儿是这么做的》操作手册，塞给他，他就照着办了。

技能本身不是软件，不会占你电脑空间，也不会自己偷偷运行。它就是一份文档 —— AI 读了它，行为就变了。

## 二、怎么把它装到自己的 AI 上

**最简单的方法（推荐给完全不懂技术的人）：**

1. 在下面的列表里找到你想要的技能，点进去；
2. 复制浏览器地址栏里的**网址**；
3. 把网址发给你平时用的 AI，跟它说一句：

   > 把这个网址里的技能装上，以后帮我干活

4. 完事。装好之后你**正常跟 AI 说话就行** —— 该用它的时候它自己会用上，不需要你每次提醒。

> 如果你用的是 DeepSeek Harness、Claude Code 这类「能自己动手改自己」的 AI，它会自己把文件放到该放的位置，你什么都不用管。

**怎么知道装上了没：** 问它一句「你现在有哪些技能？」，它能报得出来，就是装上了。

## 三、这里有什么

### `github-agent-plugin-trends` —— 帮你挑出热门的 AI 插件

**它能帮你干什么**

网上的 AI 插件每天冒出来一大堆，你不可能一个个看。这个技能会让 AI **翻一遍 GitHub 上本周（或本月）最火的插件**，挑出前 10 个，用大白话告诉你：

- 这东西是干什么的、**什么情况下你会用得上**；
- **你该怎么开口**才能让它干活；
- 它帮不上忙的地方是什么；
- 以及一条**能直接装它的网址**。

它不会甩给你一堆命令和术语 —— 整份榜单是写给不懂技术的人看的。

**怎么用**

装好之后，直接跟 AI 说：

> 帮我梳理一下这周热门的 AI 插件

它会先问你一句「要本周还是本月」，然后自己去查。

> 两点提醒：榜单里的星标数字是**抓取那一刻的快照**，随时会变；它也会老实告诉你哪些数据没查到，不会瞎编。

**里面都有什么**

| 文件 | 作用 |
| --- | --- |
| `SKILL.md` | 技能本体，AI 读的就是它 |
| `references/query-cookbook.md` | 它查资料时用到的查询手册 |
| `references/output-template.md` | 它写榜单时的格式模板 |

## 四、常见问题

**我完全不懂代码，能用吗？**
能。你要做的只有两件事：复制网址，说一句「帮我装上」。

**装错了、不想要了怎么办？**
直接跟 AI 说「把 XXX 这个技能删掉」。

**收费吗？**
不收费。这里的东西你可以随便用、随便改，甚至拿去商用，都不用署名（见下面的许可证）。

**为什么仓库名是拼音？**
GitHub 不允许仓库名用中文，只能用英文字母 —— 我试过，中文会被自动替换成横线。所以中文名字放在这里和仓库描述里。

**技能、插件、MCP 有什么区别？**
对你来说不用区分。这三个词说的都是同一件事：**给 AI 加一个能力**。装法也一样 —— 把网址给 AI 就行。
