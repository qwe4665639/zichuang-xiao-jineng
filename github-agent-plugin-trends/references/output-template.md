# 附：一条写好的完整样例（照这个写）

> 下面是 2026 年 9 月月榜 #1 的真实成稿，可作为手感基准。注意它**没有任何命令**，场景也不是从 README 抄的。

### #1 tt-a1i/archify —— 让 AI 帮你画一张能直接给人看的图
- **网址**：<https://github.com/tt-a1i/archify> —— 把这条链接丢给你的 AI，说一句"帮我装上"。
- **类型**：画图
- **热度**：月涨星 **+51,755**（本期最高）｜快照 64,910 ★（2026-09-17 09:52）｜MIT｜最近更新 2026-09-16
- **它能帮你解决什么事**：把一件复杂的事画成一张图。没有它的时候，你要么自己画一下午，要么画出来歪歪扭扭不好意思发出去。
- **你什么时候会用到它**
  - **场景一：要把一件复杂的事讲给别人听。** 比如你接手了别人做的一个流程，资料是散的，周会上得讲清楚它是怎么运转的。你跟 AI 说"把从下单到发货的流程画成一张图，要能放进汇报里的"，图就有了。
  - **场景二：想法还在脑子里，想先看清再动手。** 你说"我想做一个给客户自助预约的东西，帮我把它是怎么跑的画出来"。**这一步不需要你已经有系统、有资料**，凭你嘴上的描述它就能先画一版，你再边看边改。
- **怎么启用它**：不用学新东西，平时怎么跟 AI 说话就怎么说 —— 话里带上"画图""画流程""画架构图""画先后顺序"这类词，它自己就会接手。万一没反应，在句子里点个名："**用 archify** 帮我画一下"。
- **它最后交给你什么**：一张自带样式的网页图，浏览器直接打开就能看，也能导出成图片，发微信、贴进文档、放进汇报都行，对方不用装任何东西。
- **它帮不上忙的地方**：它画的是"流程、结构、先后顺序"这类图，不是数据图表 —— 想画带数字趋势的折线图饼图，它不是干这个的。另外图好不好看取决于你说得清不清楚，说得越具体画得越准。

# 绝对不能写进去的东西

| 禁止 | 为什么 |
| --- | --- |
| `npx …` / `/plugin …` / `docker …` / 任何命令 | 读者不敲命令；"安装方式"这一栏整体不要 |
| "安装方式""快速开始""示例 1 / 示例 2""入门 / 进阶" | 这是开发者文档的结构，不是给人看的 |
| MCP、hook、CLI、manifest、CI、token、沙箱、渲染、渐进式披露 | 读者看不懂；要表达就换成"货架""它自己会记住""图会直接给你一张能发的图片" |
| README 里原本的示例换个说法搬过来 | 那些例子假定读者会敲命令、懂术语，等于没写 |
| 同一个场景换个说法凑成两个 | 场景必须是**两种不同的处境**，否则改为写"它帮不上忙的地方" |
